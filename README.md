## О проекте

Анализ и моделирование бизнес-процессов теннисной академии. Объект исследования — процесс проведения тренировок. Цель — стандартизация процедур и обоснование автоматизации для оптимизации использования ресурсов (кортов и тренеров).

**Объект:** теннисная академия, 9 кортов (4 крытых + 5 летних), 10 тренеров  
**Исследуемый процесс:** A5.2 — Проведение тренировок (основной бизнес-процесс)

### Документация процесса

- **Карточка процесса** — владелец, входы/выходы, события начала и окончания
- **Границы процесса** — участники, ресурсы, документы
- **Бизнес-правила** — по каждому этапу (подготовка, проведение, завершение)
- **KPI** — уровень удовлетворённости клиентов ≥ 95%, целевая заполняемость кортов

## Ключевые изменения AS-IS → TO-BE

| Параметр | AS-IS | TO-BE |
|----------|-------|-------|
| Запись клиентов | Вручную через администратора | Онлайн-запись |
| Контроль расписания | Ручная сверка | Автоматическая проверка конфликтов |
| Загрузка ресурсов | Не отслеживается | Мониторинг в реальном времени |
| Отчётность | Ручная | Автоматическая генерация |
